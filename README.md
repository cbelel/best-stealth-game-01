# The Lantern Archive

"The Lantern Archive" is a top-down stealth puzzle game built for the [make.fun best-stealth-game-20261121-1759 bounty](https://make.fun/bounty/best-stealth-game-20261121-1759).

## About the Game
You play as Wren, a master thief infiltrating a moonlit museum archive at night. Your objective is to steal 3 sacred relics in each gallery and reach the glowing exit unseen. Wardens patrol the halls with lanterns, their vision cones sweeping the floor. Stay in shadow, use cover (crates, bookshelves, pillars), and sneak to avoid detection!

## How to Play
1. Navigate through 3 increasingly challenging museum galleries.
2. Collect all 3 glowing relics in each level.
3. Reach the exit portal once all relics are secured.
4. Avoid guard vision cones and bright lamplight. Running makes noise that attracts nearby guards!

## Controls
- **WASD / Arrow Keys**: Move
- **Hold Shift**: Sneak (moves slower, quieter, harder for guards to spot)
- **E**: Pick up relics
- **P / Esc**: Pause / Resume
- **M**: Toggle audio mute
- **R**: Restart current level
